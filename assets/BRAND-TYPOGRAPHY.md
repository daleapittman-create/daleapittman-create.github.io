# Studio brand typography

**Source Sans 3** is the studio's default sans, for website text, UI, pitch decks and new social templates. Keep existing sizes, line heights, and hierarchy when updating a composition. For new templates start with 400 body, 600 labels, and 650–700 headings; use italics for emphasis, not entire blocks.

- Web: load `/assets/brand-type.css` and use `var(--brand-sans)`. Both variable files are self-hosted; no third-party font request is needed.
- Deck/social authoring: install the original desktop version from [Adobe's Source Sans 3 release](https://github.com/adobe-fonts/source-sans/releases/tag/3.052R). Use live editable text in source documents and recheck line breaks.
- Keep intentional Cormorant Garamond editorial accents, client-specific typography, data/mono text, and icon faces. Product tools and archived pieces may keep their own typographic systems.
- Unmodified Adobe Source Sans 3 variable WOFF2s, release 3.052; redistribute with `fonts/source-sans-3/OFL.txt` under SIL OFL 1.1.
