Social Templates / Asset Index

Design decision

Design the return trip to the master.

A set of social templates becomes harder to use when the original assets and layout files drift apart. This kit treats finding the source as part of production.

Reusable layouts sit alongside an asset index. The unfilled wide-format master shows the underlying structure a designer starts from before replacing the content.
