Ambient Signage Studio

Design decision

Keep the menu editable after delivery.

A hospitality display needs to accommodate the next menu and the next announcement. Fixed artwork turns each of those small changes into another design request.

The prototype puts rows, imagery, type and layout under local control. The operator can save a still or run the composition as a standalone browser display.
